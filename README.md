A single line of horror, written by a small Python program. The program writes one sentence — a sleep app that recorded a stranger's voice answering questions asked in sleep, ending on the one question the sleeper never remembers asking — to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
